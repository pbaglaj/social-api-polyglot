# Projekt

<p class="editor-paragraph mb-2" dir="ltr"><span style="white-space: pre-wrap;">Backend pod sieć społecznościową lekkiego typu: profile, relacje obserwowania, posty z treścią tekstową, reakcje i komentarze. PostgreSQL utrzymuje graf obserwacji i kanoniczne rekordy postów z licznikami spójnymi z regułami transakcji. MongoDB: denormalizowany feed użytkownika (materializacja lub kolejka zdarzeń), treści rozszerzone (embedy, ankiety), agregacje trendów hashtagów lub aktywności dziennej (T7). Wymagania nie obejmują budowy interfejsu SPA — tylko API i projekt danych pod skalowalny odczyt.</span></p>
